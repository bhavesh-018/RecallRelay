# RecallRelay · Architectural Decision Log (`decision_log.md`)

| ID | Date | Decision | Rationale | Impact / Boundaries |
| --- | --- | --- | --- | --- |
| **ADR-001** | 2026-11-26 | Server-side Flagsmith evaluation via Python SDK (`>=6.3.0`) | Prevents client/server identity splits, premature exposures before pressing Start, and client-forged conversion events. | Frontend renders variant returned by FastAPI; `EventOutbox` persists events before dispatch. |
| **ADR-002** | 2026-11-26 | Run FastAPI locally on port `8080` (Vite on `5173`) | Flagsmith self-hosted Docker Compose binds `8000` (`flagsmith`) and `8001` (`flagsmith-task-processor`). | Vite dev server proxies `/api` to `http://localhost:8080`. |
| **ADR-003** | 2026-11-26 | Use `cloudflared` quick HTTPS tunnel + `/join` entry route | Gives phones instant HTTPS access without separate cloud DB delays; `/join` enables zero-friction remote study onboarding alongside `/t/<token>` QR box links. | QR generation derives host dynamically from `PUBLIC_BASE_URL` or active request origin; `/join` stores 1 session per browser and hides operator console links to prevent study contamination. |
| **ADR-004** | 2026-11-26 | Isolate `Study` vs. `Pilot` Flagsmith environments | Keeps Track 1 participant study frozen and uncontaminated while Track 2 AI agent applies and verifies real configuration writes in `Pilot`. | Agent allowlist permits writes only to `Pilot / recall_response_flow`. |
| **ADR-005** | 2026-11-26 | Use `flagsmith 6.7.0` `get_experiment_flag()` with `enable_events=True` | Built-in method enforces experiment enrollment checks before emitting `$flag_exposure` and exposes `track_event(event=..., identifier=...)` + `flush_events()`. | Prefer `flag.value` (`standard` / `guided`) over Flagsmith Cloud's internal variant key (`control` / `Variant_1`). |
| **ADR-006** | 2026-11-27 | Support Flagsmith Cloud Account Token (`Token`) fallback, integer MV option ID resolution, and v2 Feature Versioning API | Live Flagsmith Cloud environments enforce v2 Feature Versioning (`POST /versions/` → `PUT /featurestates/` → `POST /publish/`) and return integer `multivariate_feature_option` IDs. | Preserves classic v1 `PUT /featurestates/{id}/` compatibility for self-hosted or non-v2 environments. |
| **ADR-007** | 2026-11-27 | Switch default Gemini agent model to `gemini-3.5-flash-lite` with `x-goog-api-key` header | `gemini-2.5-flash` returned 404 for new API keys; `gemini-3.5-flash-lite` provides fast, reliable structured JSON proposals within the 60s agent budget. | Configurable via `LLM_MODEL` / `LLM_PROVIDER` in `.env`. |
| **ADR-008** | 2026-11-27 | Keep PostgreSQL `EventOutbox` authoritative alongside self-hosted Flagsmith | Open-source self-hosted Flagsmith returns `405` on Cloud-only event ingestion endpoints while serving multivariate flag evaluations cleanly. | Experiment counts and `scripts/export_results.py` remain 100% reproducible in both Cloud and self-hosted deployments. |
| **ADR-009** | 2026-11-28 | Add 16-location 3-tier `demo_large_drill.json` fixture alongside `food_drill.json` and `second_drill.json` | Demonstrates multi-hub scale (`1 Source → 3 Regional Hubs → 12 Retail Locations`, 500 units) without modifying core accounting or existing 5-location tests. | `seed.py --reset` clears supply-chain fixture tables cleanly while strictly preserving `DrillSession` and `EventOutbox` study records. |
